012026IoT · Mobile · Backend

NotiFire

Firmware, backend and app for a senior high STEM research team

A solar-powered smoke and fire detection system for households in Cagayan de Oro. Each ESP32 detector reads an MQ-5 gas sensor and a DHT22, sounds its buzzer locally even without Wi-Fi, and reports to a Django backend that sends room-by-room alerts to every phone in the house.

  • Detector setup from the app over Bluetooth, with Wi-Fi entered by hand or scanned from a QR code
  • Detectors shared by email so the whole household gets the same alerts
  • Event history with CSV export; runs entirely on free tiers with CI-gated deploys and backups
  • ESP32 / C++
  • Django
  • Flutter
  • Supabase
  • Firebase

032026Web app · Document tracking

Stampede

Paper trail tracking for offices that still run on folders

Every physical document gets a digital copy and a QR sticker. Each office that handles it logs the handoff with one tap, requesters track it like a parcel, and admins can see which office is slowing things down.

  • Workflow routing with an SLA per step; releasing a document moves it to the next office
  • A bottleneck heatmap built from the custody log: average time per office, plus overdue items
  • Duplicate detection by content hash and optional OCR full-text search
  • React
  • Vite
  • Node.js
  • SQLite
  • tesseract.js
